# knowledge/wiki/ —— 数仓 LLM Wiki

给 LLM 和新人看的一张地图：**表在哪、字段叫什么、词根怎么拼、指标怎么算**。

它不回答"口径是什么"——口径只在本体（`ontology/`）。wiki 只回答"去哪里找"。

## 使用规则

1. **顺序**：先用 `05` 定位表 → 用 `03`/`04` 核字段 → 最后才写 SQL。跳过前两步直接写 SQL 是最常见的返工原因。
2. **不写口径**。GMV 按什么时间归日、含不含运费，写在 [ontology/metric/atomic/gmv.yaml](../../ontology/metric/atomic/gmv.yaml)，wiki 只指路。
3. **冲突处理**：表名/字段名以 wiki 为准；与 SQL 模板冲突时，以 `templates/` 里能跑通的为准，并回头改 wiki。
4. **不在 wiki 里的表 = 临时表**。新增一张表，必须先进 `03` 或 `04`，否则别人（和 LLM）找不到它。

## 分层速览

```
ods_*       贴源，与业务库同构，只做同步不做加工        （一般只给 DWD 用，业务方不要直查）
  ↓
dwd_*_di    明细，一行一个业务事件，全字段、带 dt 分区
  ↓
dws_*_1d    汇总，按"天 + 某个维度"预聚合
  ↓
ads_*_1d    应用，宽表 / 榜单 / 漏斗，直接给报表和取数
  ↑
dim_*_df    维表，全量快照，给上面各层做 join
```

域划分：`trade`（交易）、`user`（用户）、`item`（商品）、`mkt`（营销）、`log`（行为日志）。
