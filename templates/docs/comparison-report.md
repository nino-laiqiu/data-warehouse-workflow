## 1. 差异清单

按语义 → 结构 → 实现 的顺序列，不要按文件列。同一个文件里的两个差异要分成两条。

| # | 类别 | track-1 做法 | track-2 做法 | 依据 | 裁决 |
|---|---|---|---|---|---|
| 1 | 语义 | | | `GMV` | 取 A |
| 2 | 结构 | | | 粒度=订单级 | 取 B |
| 3 | 实现 | | | knowledge/wiki/03-事实表 | 取 B |

类别只能填三项之一：

- **语义**：指标定义、归日字段、时间窗、去重键、是否含运费。没有商量余地，回本体裁决。
- **结构**：表粒度、主键、分区、join 方向。选更符合本体粒度的那个。
- **实现**：写法、性能、可读性、异常处理。选更省资源且可读的。

**依据**必须可追溯：本体 `id`、知识库路径、或契约字段。写"经验上"等于没写。
