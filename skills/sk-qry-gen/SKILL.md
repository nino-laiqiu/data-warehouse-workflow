# sk-qry-gen — 由意图与表生成一条只读取数 SQL

> 状态：**只有规格，没有实现**。本文定义"这个技能存在、什么时候被调用、凭什么算过"。
> 实现时要补：`schema.json`（输入输出契约）、`validate.py`（判据代码化）、至少 3 条正反用例。

## 什么时候被调用

A 线第 3 步；表已定位之后

## 输入

intent 契约 + 选定的表结构

## 输出

一条只读 SQL（SELECT/WITH）+ 参数说明（${dt} 等）

## 判据（怎么算过）

- 列必须存在于所选表
- 分区过滤写在 WHERE 最前
- 比率类指标禁止先算日比率再平均
- 聚合前后粒度一致

## 失败怎么处理

表结构不满足 → 返回缺口说明，不猜列名

## 不做什么

不写 DDL/DML；不优化执行计划
