# sk-lin-build — 由依赖关系生成血缘与调度

> 状态：**只有规格，没有实现**。本文定义"这个技能存在、什么时候被调用、凭什么算过"。
> 实现时要补：`schema.json`（输入输出契约）、`validate.py`（判据代码化）、至少 3 条正反用例。

## 什么时候被调用

B 线 P5；DQ 规则确定后

## 输入

所有相关 SQL + 表清单 + 调度约定

## 输出

lineage.json（契约已有）+ DAG 骨架 + 回滚步骤

## 判据（怎么算过）

- 无孤立节点（每个表有上游或标为外部源）
- 调度边无环
- 任务必须挂在调度边上
- 回滚步骤必须含重跑与质检

## 失败怎么处理

发现上游未知 → 补登记为外部源，不许留空

## 不做什么

不部署 DAG、不申请资源
